# Python med Bro Code – börja här

Vi använder bara **Bro Code** som videokurs. Gör övningarna och projekten som finns i videon; det här projektet lägger inte till egna uppgifter.

## Kursen

[Bro Code – Python Full Course for free 🐍](https://www.youtube.com/watch?v=ix9cRaBkVe0)

Börja vid **00:00**. Hoppa över installationen och PyCharm-delen – Python och VS Code finns redan på datorn.

## Så använder du projektet

1. Titta på videon och pausa när Bro Code visar ett begrepp du vill förstå.
2. Ha [BRO_CODE_GUIDE.md](BRO_CODE_GUIDE.md) öppen i VS Code. Sök i guiden efter begreppet.
3. Gör Bro Codes övning när videon kommer till den.
4. Ta ett avsnitt i taget. Du behöver inte bli klar med hela kursen snabbt.

GitHub är din onlinekopia. Jag har uppdaterat den lokala versionen av projektet; när du pushar visas den här guiden och den nya startsidan på GitHub.
